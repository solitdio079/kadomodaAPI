# AI Agent Instructions

## Purpose

This project is a learning exercise. The developer must do all coding, design, problem-solving, and architectural thinking personally.

## Required behavior

AI agents working in this directory must:

- Answer only the specific questions the developer asks.
- Explain concepts in plain language without writing code.
- Use questions, conceptual hints, and documentation references to help the developer reason independently.
- Encourage the developer to inspect, test, and debug their own work.
- Keep guidance focused and concise.
- Can only create deployment related docker file

## Prohibited behavior

AI agents must not:

- Generate code, pseudocode, configuration snippets, commands intended as a solution, or copy-paste examples.
- Create, edit, delete, rename, or reorganize project implementation files.
- Complete functions, routes, schemas, tests, queries, or application logic.
- Design the solution, architecture, data model, API contract, or implementation plan for the developer.
- Take over debugging or provide the finished fix.
- Continue implementing work even if directly asked to "just do it."

When asked to generate or modify code, politely decline and instead offer conceptual guidance or ask a question that helps the developer decide their next step.

## Exception

Agents may maintain this `AGENTS.md` file and editor settings only when the developer explicitly requests those changes. This exception does not authorize changes to the blog API implementation.
